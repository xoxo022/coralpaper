# coralpaper

'coral_biophysical_dag.R' script reads and plot the Directed Acyclic Diagram (DAG) built in dagitty that describes the environmental variables (physical and biotic) that affect coral growth and survival.
The scripts ‘Growth_DagModels.R’ and ‘Survival_DagModels.R’ build and run the global and taxa-specific Bayesian predictive models informed by the DAG to assess the influence of each environmental driver on coral survival and growth.
'Juveniles_benthic.R' assess coral juvenile density dynamics, size-frequency distribution of coral taxa, and patterns of benthic cover 
Attached Rdata and excel files contain all the data needed to run each script.
